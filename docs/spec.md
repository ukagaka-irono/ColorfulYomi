# ColorfulYomi 仕様書

> シリーズ全体の仕様書: [ColorfulTalk](https://github.com/ukagaka-irono/ColorfulTalk)（`docs/spec/yomi.md` と同じ内容）。
> 辞書は [Colorful-dictionary](https://github.com/ukagaka-irono/Colorful-dictionary)。

漢字かな交じり文を、ColorfulTalk の記号列（読み・アクセント・区切り）に変換する言語処理エンジンです。

```
今日は2026年11月5日です。
        ↓ ColorfulYomi
きょ'ーわ/にせんにじゅーろくねん/じゅーいち'がつ/いつかで'す。
```

## 主な仕様

| 項目 | 内容 |
|---|---|
| 版 | 1.0.0 |
| 言語 | C99。外部ライブラリなし |
| 対象 | Windows / macOS / Linux など、26MB の辞書を RAM に置ける環境 |
| 入力 | UTF-8 の文字列 |
| 出力 | カナ記号列（V1 / V2 / V3 用）、ローマ字記号列（nano / pico LSI 用） |
| 辞書 | Colorful-dictionary の `colorful_talk.dic`（約 48 万語）と、任意のユーザー辞書 |
| 速さ | 日常文 1,000 文を約 0.17 秒（辞書の読み込み 約 0.09 秒を除く、Windows 11・x64） |
| 大きさ | DLL 約 210KB（C ランタイムを静的リンクした値） |
| スレッド | 辞書は読み込んだ後は変更しないので、1 つの辞書を複数のスレッドから同時に使える（`cy_add_user_*` を除く） |

マイコン向けの ColorfulYomi-M（外部フラッシュの辞書を読み出し関数で引く版）は未着手です。

## API

```c
#include "colorful_yomi.h"

CyDic* dic;
char koe[1024];
size_t need;

if (cy_open("colorful_talk.dic", &dic) != CT_OK) { /* 読めない */ }
if (cy_text_to_koe(dic, "今日はいい天気です。", koe, sizeof koe, &need) == CT_OK) {
    /* koe を ct3_start() などに渡す */
}
cy_close(dic);
```

| 関数 | 内容 |
|---|---|
| `cy_version()` | 版の文字列 |
| `cy_open(path, &dic)` | 辞書ファイルを読み込む（パスは UTF-8） |
| `cy_open_memory(data, size, &dic)` | メモリ上の辞書を使う（コピーしない。4 バイト境界に置く） |
| `cy_close(dic)` | 閉じる |
| `cy_add_user_dic(dic, csv_path, &line)` | ユーザー辞書（CSV）を追加。誤りがあれば行番号を返す |
| `cy_add_user_word(dic, 表層形, 読み, アクセント, 品詞)` | 1 語を追加 |
| `cy_text_to_koe(dic, text, out, size, &need)` | カナ記号列に変換 |
| `cy_text_to_roman(dic, text, out, size, &need)` | ローマ字記号列に変換 |
| `cy_text_to_morphs(dic, text, out, size, &need)` | 調べる用。形態素を 1 行 1 語（表層形・品詞・発音・アクセント・結合規則をタブ区切り）で返す |

- 出力は NUL 終端。`out` が足りないと `CT_ERR_BUFFER` を返し、`*need` に必要なバイト数（NUL を含む）を入れます。
  `out = NULL, size = 0` で大きさだけ調べられます
- 長さの上限はありません。合成エンジンの上限（V3 は 1 回 512 モーラ）を超える長い文章は、句点ごとに分けて変換・合成してください

### エラー

| 値 | 定数 | 意味 |
|---|---|---|
| 1 | `CT_ERR_NULL` | 引数が NULL |
| 2 | `CT_ERR_UTF8` | 入力が不正な UTF-8 |
| 3 | `CT_ERR_CHAR` | ユーザー辞書の読みにカナ以外の文字がある |
| 8 | `CT_ERR_PARAM` | ユーザー辞書の項目が不正（品詞が違う、アクセントが範囲外など） |
| 10 | `CT_ERR_MEMORY` | メモリ不足 |
| 12 | `CT_ERR_IO` | ファイルを読めない |
| 13 | `CT_ERR_DIC` | 辞書の形式が違う・壊れている |
| 14 | `CT_ERR_BUFFER` | 出力先が足りない |

## ユーザー辞書

CSV（UTF-8、BOM 可）で、1 行 1 語です。1 行目が `表層形` で始まる見出し行と、`#` で始まる行は読み飛ばします。

```
表層形,読み,アクセント,品詞
ColorfulTalk,カラフルトーク,5,固有名詞
伺か,ウカガカ,0,固有名詞
```

| 列 | 内容 |
|---|---|
| 表層形 | 文中の書き方。英数字の全角・半角は区別しない |
| 読み | カタカナまたはひらがな（長音は「ー」） |
| アクセント | 核の位置（0 = 平板、1 = 頭高、n = n モーラ目の後で下がる） |
| 品詞 | `名詞` `サ変名詞` `固有名詞` `人名` `地名` `組織` `感動詞`（省略すると `名詞`） |

ユーザー辞書の語は辞書の語より優先します。同じ表層形を登録し直すと置き換わります。

## 処理

1. **正規化**: 英数字・記号を全角に、半角カナを全角に（濁点・半濁点もまとめる）。かなの後の「〜」は長音
2. **数**: 数字の並び（`1,234.5` の形）を 1 語として読む。万・億・兆・京の位取り、`300`→さんびゃく などの音の変化、
   小数（てん）、0 で始まる番号や `090-1234-5678` のようにハイフンでつながった数字は 1 けたずつ
3. **形態素解析**: 辞書の語と未知語（文字種ごとにまとめる）でラティスを作り、語のコストと連接コストの和が最小の区切りを選ぶ（ビタビ探索）
4. **助数詞**: 数の後の助数詞で音を変える。`1本`→いっぽん、`3本`→さんぼん、`6分`→ろっぷん、`8階`→はっかい、`4月`→しがつ、
   `4時`→よじ、`1人`→ひとり、`5日`→いつか、`1日`（月の後）→ついたち、`3つ`→みっつ など
5. **アクセント句**: 自立語に、助詞・助動詞・接尾辞・非自立語をつなげる。名詞の連続（複合語）、接頭辞 + 名詞、
   数 + 名詞、サ変名詞 + する、英字の並びも 1 つの句にする
6. **アクセント核**: 句の最初の語の核から始め、つながる語ごとに辞書の結合規則で核を動かす（下の表）。
   核が特殊モーラ（ー・ッ・ン）に当たるときは 1 つ前へずらす
7. **出力**: 発音をひらがなにし、核の後に `'`、句の間に `/`、読点 `、`、文末 `。` `？` `！` を入れる。
   読めない文字（辞書にない漢字など）は読み飛ばす

### アクセント結合規則

句の中で、それまでのモーラ数を M、それまでの核を A、つながる語の核を a とします。

| 規則 | 種類 | 新しい核 |
|---|---|---|
| C1 | 複合名詞: 後の語の核を残す | a = 0 なら 0、それ以外は M + a |
| C2 | 複合名詞: 後の語の 1 モーラ目 | M + 1 |
| C3 | 複合名詞: 前の語の最後のモーラ | M |
| C4 | 複合名詞: 平板 | 0 |
| C5 | 複合名詞: 前の語の核を残す | A |
| F1 | 付属語: 前に従う | A |
| F2@n | 付属語: 前が平板なら付属語に核 | A = 0 なら M + n、それ以外は A |
| F3@n | 付属語: 前に核があれば付属語へ | A ≠ 0 なら M + n、それ以外は A |
| F4@n | 付属語: 付属語に核 | M + n |
| F5 | 付属語: 平板にする | 0 |
| P1 | 接頭辞: 後の語と一体 | a = 0 なら 0、それ以外は M + a |
| P2 | 接頭辞: 後の語の核を残す | M + a（a = 0 なら M + 1） |

付属語の規則は `名詞%F2@1/動詞%F1` のように前の語の品詞ごとに書かれていて、直前の語の品詞に合うものを使います。
合うものがなければ F1 とします。

## 精度

[accuracy.md](accuracy.md) を参照してください。日常文 100 文で、読みの文単位の一致率は 97% です。
